# 🚗 Smart Car Price Predictor

A Machine Learning web application built with **Python**, **Scikit-Learn**, and **Streamlit** to estimate the selling price of used cars based on various features.

---

## ✨ Features
* 📊 **Machine Learning Model:** Random Forest Regressor for price estimation.
* ⚡ **Interactive UI:** Built using Streamlit for an easy-to-use web interface.
* 🎯 **Key Inputs:** Car purchase year, current showroom price, distance driven, fuel type, and transmission mode.

---

## 🛠️ Tech Stack
* **Language:** Python
* **Machine Learning:** Scikit-Learn, NumPy, Pandas
* **Web Framework:** Streamlit

---
## 🚀 How to Run Locally

1. **Clone the Repository:**
```bash
   git clone https://github.com/khushisaini221005/smart-car-price-predictor.git
   cd smart-car-price-predictor
```
2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
```
3. **Train Model:**
   ```bash
   python train_model.py
```
4. **Run Streamlit App:**
   ```bash
   streamlit run app.py
   ```
